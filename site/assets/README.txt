PassQuest — exam logo assets
============================

passquest.html references the official exam logos from this folder, in the
exam ticker and the exam tab list. Save each official logo here with the exact
filename below (transparent PNG or SVG):

  ielts.png— IELTS
  celpip.png— CELPIP
  gre.png— GRE
  sat.png— SAT
  toefl.png— TOEFL

Notes
-----
- Use the vendors' own official logo files. They render at ~20-22px tall on
  the page; the ticker shows them de-saturated, the selected exam tab shows
  them in full colour.
- Until a file is added, the page falls back to the exam name as text
  (the img alt attribute).
- Keep the source-provided artwork intact — don't recolour or redraw the marks.
